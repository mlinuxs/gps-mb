# CSV 日志格式说明

## 1. 文件位置与命名

- 目录：手机内部存储公共下载目录
  - 实际路径：`/storage/emulated/0/Download/`
  - 系统「文件管理」→「下载」中可见
- 文件名：`RideLog_yyyyMMdd_HHmmss.csv`
  - 例：`RideLog_20260904_120530.csv`
- 编码：**UTF-8（带 BOM）**，Excel / WPS 直接双击打开中文表头不乱码
- 无需 ROOT，停止记录后文件即写入完成（每条记录实时 flush，异常断电最多丢失 1 秒）

## 2. 字段定义

点【开始记录】时新建文件并写入表头；之后**每秒追加一行**：

```
时间,电压(V),电流(A),电量(%),温度(℃),经度,纬度,海拔(m),瞬时速度(km/h),总里程(km),坡度(%)
2026-09-04 12:05:31,53.21,-2.35,87,26.4,116.391234,39.907888,42.5,18.6,0.423,1.2
```

| 序号 | 字段 | 说明 | 空值条件 |
|---|---|---|---|
| 1 | 时间 | 本地时间，`yyyy-MM-dd HH:mm:ss`，精确到秒 | 不会为空 |
| 2 | 电压(V) | 保护板电池电压，保留 2 位小数 | 未连接蓝牙/无数据时为空 |
| 3 | 电流(A) | 有符号电流，保留 2 位小数；方向由保护板固件定义 | 同上 |
| 4 | 电量(%) | 剩余电量整数，0~100 | 同上 |
| 5 | 温度(℃) | 电池温度，保留 1 位小数 | 同上 |
| 6 | 经度 | WGS84 坐标系，6 位小数 | GPS 未定位时为空 |
| 7 | 纬度 | WGS84 坐标系，6 位小数 | GPS 未定位时为空 |
| 8 | 海拔(m) | 滑动平均后海拔，保留 1 位小数，**仅作参考** | 未定位时为空 |
| 9 | 瞬时速度(km/h) | 滤波后速度，保留 1 位小数 | 未定位时为空 |
| 10 | 总里程(km) | Haversine 公式累加，保留 3 位小数 | 未定位时为空（定位后从 0 起） |
| 11 | 坡度(%) | 相邻采样点海拔差/水平距离，滤波+±40%限幅，**仅作参考** | 未定位时为空 |

> 说明：未连接蓝牙或 GPS 未定位的行，对应列留空，仍会记录时间与已可用的数据。

## 3. 导入运动软件

| 软件 | 导入支持 | 操作建议 |
|---|---|---|
| Excel / WPS | 直接打开 | 双击文件即可；UTF-8 BOM 已写入，中文不乱码 |
| 行者 / 黑鸟 | 官方导入以 GPX/FIT 轨迹文件为主 | 将 CSV 中「经度/纬度/时间」转换为 GPX 后导入 |
| Strava | 仅支持 GPX/FIT/TCX 上传，**不直接支持 CSV** | 需先转换为 GPX/FIT |
| 其他分析 | 任意支持 CSV 的工具 | 直接加载，逗号分隔 |

### CSV → GPX 快速转换（任选其一）

1. **GPS Visualizer（在线）**：访问 https://www.gpsvisualizer.com/ ，选择 convert to GPX，
   上传 CSV，字段映射时经度选「经度」、纬度选「纬度」、时间选「时间」即可生成 GPX。
2. **GPSBabel（本地软件）**：
   ```
   gpsbabel -i unicsv -f RideLog_20260904_120530.csv -o gpx -F ride.gpx
   ```
3. 生成的 `ride.gpx` 即可导入行者/黑鸟/Strava。

> 注意：本 APP 输出的 CSV 是**完整原始数据日志**（含电池信息），运动轨迹分享用 GPX 转换件，
> 电池/里程/坡度分析直接用 Excel 处理 CSV。
